GitHub Collaboration

A simple tutorial for working on a project with other people.

The basic idea

Git keeps a history of your code changes. GitHub stores a Git project online so teammates can share work and review changes. A branch is a separate workspace; a pull request (PR) asks the team to review and merge your work.

1 · Get the project

Clone the repository

Get the project URL from GitHub. If you do not have permission to write to it, fork it first and use the URL of your fork.

git clone https://github.com/OWNER/PROJECT.git
cd PROJECT

2 · Work safely

Create a branch

Make a new branch for one focused task rather than changing the shared main branch directly.

git switch -c fix-homepage-title

3 · Save and publish

Commit your changes

Edit your files, then save a checkpoint and send your branch to GitHub.

git add .
git commit -m "Fix homepage title"
git push -u origin fix-homepage-title

4 · Ask for review

Open a pull request

On GitHub, select Compare & pull request. Explain what you changed and why, then create the PR. Teammates can comment, suggest improvements, and approve it. Make requested updates on the same branch and push again.

5 · Merge and repeat

Update your local project

After the PR is approved and merged, update your local main branch before starting another task.

git switch main
git pull origin main
git switch -c next-task

Remember: Keep changes focused, write clear commit messages, and communicate with your collaborators during review.

Branch → change → commit → push → open a PR → review → merge
